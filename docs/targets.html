새로운 모니터링 타겟 추가 방법

GitHub 저장소의 targets.json 파일에 JSON 오브젝트를 추가하고 커밋 & 푸시하면 GitHub Actions가 다음 주기부터 자동으로 새 타겟의 릴리즈를 크롤링하고 Vector DB에 색인합니다. 

{
  "Id": "rust",
  "Name": "Rust 언어",
  "Category": "Programming Language",
  "Type": "GitHubRelease",
  "SourceUrl": "https://api.github.com/repos/rust-lang/rust/releases",
  "WebChangelogUrl": "https://blog.rust-lang.org/",
  "Description": "Rust 공식 릴리즈 및 체인지로그"
}
